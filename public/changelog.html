Changelog

Catatan perubahan Dukung.in.

Versi 0.1, 30 September 2026

Fitur kreator

  • Akun kreator dengan halaman dukungan sendiri
  • Foto profil, kategori, dan tombol nominal cepat yang bisa diatur
  • Dashboard dengan menu Halaman, Pemasukan, Penarikan, Overlay OBS, dan Keamanan
  • Overlay OBS untuk notifikasi dukungan di stream
  • Halaman Temukan kreator dan FAQ
  • Foto banner, tautan sosial media, dan peringatan 18+ di halaman kreator

Pembayaran dan saldo

  • Pembayaran QRIS lewat Tripay
  • Saldo kreator dengan potongan platform 10%
  • Pengajuan penarikan ke bank atau e-wallet, diproses admin

Keamanan

  • Batas percobaan login dan pendaftaran
  • Sesi login otomatis kedaluwarsa
  • Ganti password dan reset password lewat admin
  • Backup data otomatis

Tampilan

  • Landing page baru dan tema gelap di semua halaman
  • Halaman Status layanan
